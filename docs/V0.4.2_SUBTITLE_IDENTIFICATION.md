# v0.4.2 subtitle-assisted identification — development test

This experimental module is **not** a stable release or guaranteed automatic title recognizer.
It runs on your Windows desktop, without rewriting or moving source MKVs.

## Workflow
1. Launch the Python/PySide6 development build with `START_WINDOWS.bat` and import your MakeMKV files.
2. Select one imported row and click **Analyse subtitles**.
3. The program checks subtitle streams with FFprobe and extracts supported text tracks via FFmpeg into a temporary folder.
4. Select a separate **local folder containing known reference subtitles/transcripts** (`.srt`, `.vtt`, `.ass`, `.ssa`, `.txt`). If you cancel, the app only inspects/extracts embedded tracks.
5. Review ranked reference-file names, overlap scores, matching dialogue-cue counts, and warnings. Compare against other evidence before manually entering or approving an episode/movie title.
6. The existing copy-only, SHA-256 verified export still requires manual per-file approval.

## Important limitations
- Reference subtitles must be obtained by the user with appropriate access/rights. **The app does not automatically download subtitles or infer every movie from a video scene.**
- **Image subtitles** such as DVD `dvd_subtitle` (VobSub) and Blu-ray `hdmv_pgs_subtitle` (PGS) are detected but **cannot yet be OCR'd**. Many MakeMKV DVDs contain image-based subtitles.
- Embedded text subtitle tracks supported by FFmpeg (SubRip, ASS, SSA, WebVTT, mov_text) are extracted as SRT; FFmpeg must be on PATH.
- Overlap score is a heuristic **not a percentage probability of correct identification**. At least three matched cues and 25 distinct five-word windows are required for a supported candidate. Common short phrases cannot confirm content.
- Different cuts, language choices, captions, OCR errors and differing editions may cause false negatives. An identical line doesn't prove a match.
- Movie/episode name must still be reviewed and explicitly approved. Analysis results are saved in the project record/report; extracted subtitle text is kept only in a temporary directory and discarded.
- Selecting a local subtitle-reference folder shares no material outside the computer.

## Automated checks
Run `python -m unittest discover -s tests -v` and `python -m compileall -q main.py core.py metadata.py subtitle_match.py tests`.

The automated tests use synthetic dialogue and mocks; actual subtitle extraction on real DVD/BD MKVs has **not yet been confirmed on the user's Windows system**.

## Next development steps
Optional image-subtitle OCR, automated/reference acquisition under appropriate service terms, subtitle-based candidate suggestions in the main results panel, and independently validated visual content matching. Audio transcription stays a later iteration.

Source protection is nonnegotiable: never modify/rename/move/delete source MKVs, never overwrite output, and never skip export SHA-256 verification.
