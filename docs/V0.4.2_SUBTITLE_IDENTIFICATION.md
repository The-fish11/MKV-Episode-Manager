# v0.4.2 — Title-assisted automatic subtitle matching (development test)

**This is a development build, not a stable release.** You do not need a local reference subtitle library.

## Windows test workflow
1. Install FFmpeg/FFprobe on PATH. For image-based DVD VobSub and Blu-ray PGS subtitle OCR, install a compatible Subtitle Edit `seconv` CLI and Tesseract on PATH as well (optional until OCR tested).
2. Obtain your own SubDL API key at https://subdl.com/api-doc. Enter it in the masked **SubDL key** field. It is not saved in projects or source control.
3. Select **Movie** or **Complete/Incomplete TV Season**. Enter the **movie or television series title from the DVD cover** in Title. For TV, choose the season number. Generic MakeMKV filenames are intentionally ignored.
4. Import a MakeMKV folder, select one MKV row, and click **Analyse subtitles**.
5. The application searches SubDL using the title, TMDB ID if selected, and TV season; downloads a bounded group of available reference subtitles to a temporary directory; reads embedded subtitle text, or **attempts local OCR** if only image-based subtitles are present and compatible OCR tools are installed.
6. It compares the dialogue against reference subtitle files, displays ranked reference candidates (including season/episode identifiers where present), overlap score and matching cue/window counts.
7. Review the candidate manually, enter or correct the naming details, and explicitly approve each output before SHA-256 verified copy-only export.

## Current limits / integrity
- A SubDL API key is required for automated *online* reference retrieval. The user's TMDB token is separate and cannot authenticate SubDL. API quotas, provider availability and legal terms apply.
- SubDL searches by the **provided title or selected TMDB ID**, not unknown dialogue. This is why the DVD cover title is valuable.
- For image subtitle OCR, `seconv` and `tesseract` must be present on Windows PATH; this optional integration is **not yet verified on a real Windows DVD rip**. An explicit OCR status indicates if tools are missing or OCR fails.
- For supported FFmpeg text subtitles, direct extraction does not need OCR.
- Scene fingerprints and independent visual reference matching are still not implemented; the existing scene-gallery is only for review.
- A download missing, wrong-language transcript, DVD-versus-broadcast cut, OCR mistakes, single-phrase similarity, or subtitles missing entirely can cause false negatives. Reports indicate when content is unverified.
- Overlap score is an uncalibrated **heuristic, not percentage accuracy**. At least 3 independent cues and 25 five-word windows must overlap before a candidate is considered supported.
- The tool never changes originals or auto-approves guesses; online references are downloaded temporarily; credentials are never logged.
- A small subset of online candidates is used to respect provider limits; a miss isn't proof no reference exists.
- CI tests are synthetic and offline. Actual SubDL account access and Windows image-subtitle OCR still need user testing.
