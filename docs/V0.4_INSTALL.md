# Installing v0.4 on Windows 11

1. Obtain the **v0.4 source ZIP** from the approved project package.
2. Extract the files to a fresh folder.
3. Install Python **3.11 or 3.12, 64-bit** and ensure the Python launcher is available.
4. Double-click `START_WINDOWS.bat`. It creates a virtual environment and installs `PySide6`.
5. Optional: Install FFmpeg/FFprobe and add their executables to PATH for video inspection and thumbnails.
6. Import test **copies** of MakeMKV files, choose Movie / Complete TV Season / Incomplete TV Season, assign titles/episode numbers manually, and approve proposed names.
7. Export to a separate **empty output directory**. Check that SHA-256 verified-copy results show no failures and originals remain unchanged.
8. To run safety-oriented unit tests: `python -m unittest discover -s tests -v`.

Never store TMDB API keys or personal DVD rips in the public repository. Do not commit MKV video files.
