# MKV Episode Manager v0.4 — Windows 11 test build

This is a **real, runnable early v0.4 build**, not a mockup. It focuses on safe importing, technical inspection, manual episode assignment, review, reports, and verified copying. **Automatic dialogue/subtitle-based episode identification is not implemented yet.** No file is ever renamed, deleted, moved or overwritten by this application.

## Install and run (Windows 11)

1. Install Python 3.11 or 3.12 from python.org (tick **Add Python to PATH**).
2. Extract this ZIP to a folder.
3. Double-click `START_WINDOWS.bat` (it creates a virtual environment and installs PySide6; internet needed for first run).
4. Optionally install FFmpeg and add `ffprobe.exe` and `ffmpeg.exe` to PATH for codec details and thumbnails. The app still works without FFmpeg, with reduced inspection.

## Workflow

1. Choose exactly one mode: Complete TV Season, Incomplete TV Season, or Movie.
2. Select a folder of MKV files. Files are scanned **read-only**.
3. Enter a series title, season number, and episode number/title for each file (or a movie title and year). You can edit the proposed filename in the table. The application **does not know which ripped file corresponds to which episode**; do not assume MakeMKV title order is episode order.
4. Select files and use **Preview selected** (VLC or your default player opens the original file), **Generate thumbnail** (FFmpeg), and **Inspect**.
5. Check the approval box for each verified row. Click **Export approved copies** and choose a **different, empty output directory**. Output files are copied using an exclusive create and temporary `.part` file; SHA-256 hashes are checked before finalizing. Never use an output folder inside your source folder.
6. Use **Save project** to resume and **Export diagnostic report** to get a JSON report. Reports omit API keys.

## Important limitations

- This build **does not automatically match episodes by dialogue, audio fingerprints or subtitles**. Automatic metadata lookups, TMDB/TheTVDB API connectivity, missing-episode comparison to official catalogs, and online database health checks are planned but not operational in this build.
- Duplicate detection is based on **full-file SHA-256** when you run **Check duplicates**; this can take time. Different encodes of the same episode won't match.
- Missing-episode checks are based on manually entered episode numbers, not an authoritative season list. Incomplete-season mode does not flag gaps.
- The app requires explicit manual approval of each filename; it cannot guarantee that your manual episode assignments are correct.
- FFmpeg thumbnail generation is optional and writes only to the application's temporary directory.
- Export never overwrites an existing destination. On interruption, a `.part` file may remain in the output folder and can be removed manually after checking it isn't in use.
- Test with **copies of a small number of MKVs** first. Do not treat this as production-ready until you've validated it on your own Windows machine.

## Development/test

Run `python -m unittest discover -s tests -v` for safety-oriented tests (no GUI dependency for core tests).
