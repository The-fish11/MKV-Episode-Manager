# MKV Episode Manager v0.4 — test notes

**Status:** Test build / release candidate, not yet approved as a stable release.
**Platform:** Windows 11, Python 3.11 or 3.12, PySide6.
**Source:** User-tested v0.4 test archive, not the later v0.4.1 visual-identification iteration.

## Confirmed in user's Windows 11 testing
- Application launched and displayed the PySide6 dark interface.
- Imported a MakeMKV rip of *A Knight's Tale*.
- FFprobe technical inspection reported 720 × 576 MPEG-2, about 126 minutes, two audio tracks, three subtitle tracks.
- FFmpeg generated and displayed a scene thumbnail.
- The saved project reopened with movie title, year, and proposed filename intact.
- User reported that the export renamed the copy correctly to *A Knight's Tale (2001).mkv*.

## Not yet independently confirmed on the user's system
- SHA-256 verification result (user did not report the exact verified/failed counts).
- Full-season handling, duplicate detection, failure/interruption paths, and restoring large projects.
- Thorough Windows and GUI test coverage.

## Known limitations
- Movie title/year are **entered manually** in v0.4; automatic TMDB identification is NOT included.
- Dialogue/audio episode matching and automatic scene-to-episode identification are NOT implemented.
- Missing episode detection uses manual episode numbers, not an official catalogue.
- Duplicate detection checks byte-identical hashes only.
- Technical inspection and thumbnails depend on FFprobe/FFmpeg.
- Extra .part files can remain after interrupted or failed export; sources are never touched.
- No one-click Windows installer; Python and dependencies must be installed.

## Original-file protection
Source files are read-only to application operations. Copy-only export requires explicit row approval, rejects existing targets, copies first to .part staging, checks SHA-256 equality, and finalizes without overwriting the existing destination. Keep the output folder separate from the input folder. Always validate with test copies before production use.

## Roadmap and release discipline
v0.4.1 adds online TMDB identification, posters, season metadata and multi-frame previews; it is a separate development effort. Future iterations target season-level matching then audio/dialogue matching. **Do not merge or publish v0.4 as a stable release until the repository owner approves.**
